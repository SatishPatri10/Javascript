## 🚀 Getting Started

### Prerequisites

You need [Node.js](https://nodejs.org/) installed on your machine.

To verify your installation:

```bash
node -v
```

### Running the Programs

Clone or download this repository, navigate to the project directory, and run any file directly using Node.js:

```bash
# Example 1: Run Two Sum solution
node Common/twoSum.js

# Example 2: Run Binary Search Tree implementation
node Common/bst.js

# Example 3: Run GFG Alternate Elements problem
node GFG/AlternateElementsofanArray.js
```
